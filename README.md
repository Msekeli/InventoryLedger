# Spaza Stock Manager

Spaza Stock Manager is a modern ERP-style inventory and stock management system built for small retail and spaza shop operations.

The application focuses on inventory visibility, stock movement tracking, operational dashboards, supplier management, and role-based workflows using modern full-stack .NET architecture and Azure cloud technologies.

---

# Tech Stack

## Frontend

- Blazor WebAssembly (.NET 8)
- Radzen Components

- Component-driven architecture
- Responsive ERP-style UI

## Backend

- ASP.NET Core Web API (.NET 8)

- DTO-based communication

## Database & Cloud

- Azure SQL Database Serverless
- Stored Procedures
- Relational database design
- Azure-focused architecture

# Project Goals

This project was designed to simulate a small-business ERP inventory platform while applying modern full-stack .NET development practices and enterprise architecture principles.

The goal was not only to build CRUD functionality, but to create operational workflows and role-based inventory experiences similar to real business systems.

The application also serves as a practical learning project for:

- Clean Architecture
- Cloud-based development
- Azure services
- ERP workflow simulation
- Inventory operations management
- Full-stack .NET engineering
